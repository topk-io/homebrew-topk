# homebrew-topk

Homebrew tap for the TopK CLI.

## Install

Make sure [Homebrew](https://brew.sh) is installed before using this tap.

```bash
brew tap topk-io/topk
brew install topk
```

## Upgrade

```bash
brew update
brew upgrade topk
```

## Uninstall

```bash
brew uninstall topk
brew untap topk-io/topk
```

## About

This tap provides the official Homebrew formula for the TopK CLI.

For documentation, visit https://docs.topk.io
